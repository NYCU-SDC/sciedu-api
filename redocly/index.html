Questions_upsertCorrectAnswer

Create or fully replace the question-global correct answer. Requires EXPERIMENTER or ADMIN. The first correct answer uses version 1. A changed answer increments the version and synchronizes every automatically gradable stored submission across experiments. The status is SYNCED immediately when no eligible submissions exist; otherwise it is PENDING until every eligible result uses the current version. An identical update does not increment the version or enqueue duplicate work. If the current status is FAILED, an identical update retries only the missing synchronization work and changes the status to PENDING. Completion of work for an older version must not overwrite the status of a newer version. Currently, eligible submissions are CHOICE answers from AUTOMATIC experiments. MANUAL results are not invalidated by a correct-answer update. Future automatically graded methods, including LLM grading, are also eligible.
